# Руководство по Получению API Ключей

**Дата**: 18 октября 2024  
**Проект**: Textropy

---

## Зачем Нужны API Ключи?

API ключи позволяют использовать сервисы машинного перевода для анализа текстов на разных языках. В Textropy
поддерживаются:

- **Yandex Translate** - бесплатный тариф до 1 млн символов/месяц
- **Google Translate** - бесплатный кредит $300 на 90 дней
- **DeepL** - бесплатный тариф до 500,000 символов/месяц

---

## 1. Yandex Translate API

### Преимущества

- ✅ **Бесплатный тариф**: 1 млн символов в месяц
- ✅ Отличное качество для русского языка
- ✅ Быстрая регистрация
- ✅ Простая интеграция

### Шаг 1: Регистрация в Yandex Cloud

1. Перейдите на **https://cloud.yandex.ru/**
2. Нажмите **"Войти"** или **"Зарегистрироваться"**
3. Используйте аккаунт Яндекс или создайте новый
4. Примите условия использования Yandex Cloud

### Шаг 2: Создание Платёжного Аккаунта

1. После входа нажмите **"Создать платёжный аккаунт"**
2. Выберите тип: **"Физическое лицо"**
3. Заполните данные:
    - Страна: Россия
    - Имя и фамилия
    - Email
4. Нажмите **"Создать"**

> **Примечание**: Для бесплатного тарифа не требуется привязка карты

### Шаг 3: Создание Каталога

1. В консоли Yandex Cloud перейдите в **"Каталоги"**
2. Нажмите **"Создать каталог"**
3. Укажите имя, например: `textropy`
4. Нажмите **"Создать"**

### Шаг 4: Включение Translate API

1. В левом меню найдите **"Translate"** или используйте поиск
2. Нажмите **"Начать использовать"**
3. Выберите созданный каталог
4. Подтвердите активацию сервиса

### Шаг 5: Создание API Ключа

1. Перейдите в **"Сервисные аккаунты"** (Service Accounts)
2. Нажмите **"Создать сервисный аккаунт"**
3. Укажите имя: `textropy-translate`
4. Назначьте роль: **`ai.translate.user`**
5. Нажмите **"Создать"**

6. Откройте созданный сервисный аккаунт
7. Перейдите на вкладку **"API-ключи"**
8. Нажмите **"Создать API-ключ"**
9. Скопируйте и сохраните ключ (он показывается только один раз!)

### Формат Ключа

```
AQVN****************************
```

### Добавление в Проект

**backend/.env**:

```env
YANDEX_API_KEY=AQVN****************************
```

### Документация

- https://cloud.yandex.ru/docs/translate/
- https://cloud.yandex.ru/docs/translate/quickstart

## 2. Google Translate API

### Преимущества

- ✅ **Бесплатный кредит**: $300 на 90 дней для новых пользователей
- ✅ Поддержка 100+ языков
- ✅ Высокое качество перевода
- ✅ Надёжная инфраструктура Google

### Шаг 1: Создание Google Cloud Аккаунта

1. Перейдите на **https://cloud.google.com/**
2. Нажмите **"Get Started for Free"** (Начать бесплатно)
3. Войдите с Google аккаунтом или создайте новый
4. Примите условия использования

### Шаг 2: Настройка Платёжного Аккаунта

1. Заполните информацию:
    - Страна
    - Тип аккаунта: Individual (Физическое лицо)
    - Адрес
2. **Привяжите банковскую карту** (необходимо для верификации)
    - С карты спишут и вернут $1 для проверки
    - Автоматическое списание только после окончания пробного периода
3. Подтвердите создание аккаунта

> **Примечание**: $300 бесплатного кредита хватит на ~150 млн символов

### Шаг 3: Создание Проекта

1. Перейдите в **Console** (https://console.cloud.google.com/)
2. В верхнем меню нажмите на **название проекта** → **"New Project"**
3. Укажите имя проекта: `Textropy`
4. Нажмите **"Create"**
5. Выберите созданный проект в верхнем меню

### Шаг 4: Включение Cloud Translation API

1. В поиске консоли введите: `Cloud Translation API`
2. Нажмите на **"Cloud Translation API"**
3. Нажмите **"Enable"** (Включить)
4. Дождитесь активации (несколько секунд)

### Шаг 5: Создание API Ключа

1. В левом меню выберите **"APIs & Services"** → **"Credentials"**
2. Нажмите **"+ CREATE CREDENTIALS"**
3. Выберите **"API key"**
4. Ключ будет создан автоматически
5. **Скопируйте ключ** и сохраните его

### Шаг 6: Ограничение Ключа (Рекомендуется)

1. После создания нажмите **"RESTRICT KEY"**
2. **Application restrictions**:
    - Выберите **"IP addresses"**
    - Добавьте ваш IP или оставьте `0.0.0.0/0` для тестирования
3. **API restrictions**:
    - Выберите **"Restrict key"**
    - Выберите только **"Cloud Translation API"**
4. Нажмите **"Save"**

### Формат Ключа

```
AIza****************************
```

### Добавление в Проект

**backend/.env**:

```env
GOOGLE_API_KEY=AIza****************************
```

### Мониторинг Использования

1. В консоли перейдите в **"Billing"** → **"Reports"**
2. Отслеживайте использование кредитов

### Документация

- https://cloud.google.com/translate/docs
- https://cloud.google.com/translate/docs/setup
- https://cloud.google.com/translate/pricing

## 3. DeepL API

### Преимущества

- ✅ **Бесплатный тариф**: 500,000 символов/месяц
- ✅ Лучшее качество перевода (по многим оценкам)
- ✅ Простая регистрация
- ✅ Не требуется карта для бесплатного тарифа

### Шаг 1: Регистрация DeepL API Free

1. Перейдите на **https://www.deepl.com/pro-api**
2. Нажмите **"Sign up for free"** (Зарегистрироваться бесплатно)
3. Или перейдите сразу: **https://www.deepl.com/pro#developer**

### Шаг 2: Создание Аккаунта

1. Заполните форму регистрации:
    - Email
    - Пароль
    - Страна
2. **Для бесплатного API**:
    - Выберите **"DeepL API Free"**
    - Укажите данные банковской карты (для верификации)
    - **Важно**: С карты НЕ будет списаний на бесплатном тарифе
3. Подтвердите email

> **Альтернатива**: Если не хотите указывать карту, используйте **DeepL API Pro** (платный, но есть trial)

### Шаг 3: Получение API Ключа

1. После регистрации войдите в **Account** (https://www.deepl.com/account)
2. Перейдите на вкладку **"API"** или **"Account"**
3. Найдите раздел **"Authentication Key for DeepL API"**
4. Скопируйте ключ

### Типы Ключей

**DeepL API Free**:

```
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx
```

(заканчивается на `:fx`)

**DeepL API Pro**:

```
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

### Добавление в Проект

**backend/.env**:

```env
DEEPL_API_KEY=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx
```

### Мониторинг Использования

1. В аккаунте DeepL перейдите в **"Usage"**
2. Отслеживайте количество переведённых символов
3. Лимит: 500,000 символов/месяц (Free) или по подписке (Pro)

### Документация

- https://www.deepl.com/docs-api
- https://www.deepl.com/pro-api
- https://support.deepl.com/hc/en-us/articles/360020695820

## Настройка Textropy с API Ключами

### 1. Откройте файл конфигурации

**backend/.env**:

```env
# Server Configuration
PORT=8080
GIN_MODE=debug

# Translation API Keys
YANDEX_API_KEY=AQVN****************************
GOOGLE_API_KEY=AIza****************************
DEEPL_API_KEY=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx

# CORS
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173
```

### 2. Перезапустите Backend

```powershell
# Если используете Docker
docker compose restart backend

# Или пересоберите полностью
docker compose down
docker compose up --build -d

# Для локальной разработки
cd backend
go run cmd/api/main.go
```

### 3. Проверьте логи

```powershell
docker compose logs backend
```

Вы должны увидеть:

```
INFO:  Сервис переводов инициализирован
```

2. **Для международных проектов**: Google Translate (больше языков)
3. **Для максимального качества**: DeepL (лучшие переводы, но меньше языков)

## Безопасность API Ключей

### ⚠️ Важно!

1. **Никогда не коммитьте ключи в Git**
    - `.env` файлы уже в `.gitignore`
    - Используйте `.env.example` для шаблонов

2. **Ограничьте ключи**
    - Google: Ограничьте по IP и API
    - Yandex: Используйте сервисные аккаунты с минимальными правами
    - DeepL: Мониторьте использование

3. **Храните ключи безопасно**
    - Используйте менеджеры паролей
    - Не передавайте ключи по незащищённым каналам

4. **Мониторьте использование**
    - Регулярно проверяйте статистику
    - Установите алерты на превышение лимитов

### Что делать если ключ утёк?

1. **Немедленно отзовите ключ**:
    - Yandex: Удалите API-ключ в консоли
    - Google: Delete credentials
    - DeepL: Regenerate key

2. **Создайте новый ключ**

3. **Проверьте статистику использования** на предмет необычной активности

## Тестирование API Ключей

### Проверка Yandex

```powershell
$headers = @{
    "Authorization" = "Api-Key AQVN****************************"
    "Content-Type" = "application/json"
}

$body = @{
    texts = @("Hello world")
    targetLanguageCode = "ru"
} | ConvertTo-Json

Invoke-WebRequest -Uri "https://translate.api.cloud.yandex.net/translate/v2/translate" `
  -Method POST `
  -Headers $headers `
  -Body $body
```

### Проверка Google

```powershell
$apiKey = "AIza****************************"
$text = "Hello world"
$target = "ru"

Invoke-WebRequest -Uri "https://translation.googleapis.com/language/translate/v2?key=$apiKey&q=$text&target=$target"
```

### Проверка DeepL

```powershell
$headers = @{
    "Authorization" = "DeepL-Auth-Key xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx"
    "Content-Type" = "application/json"
}

$body = @{
    text = @("Hello world")
    target_lang = "RU"
} | ConvertTo-Json

Invoke-WebRequest -Uri "https://api-free.deepl.com/v2/translate" `
  -Method POST `
  -Headers $headers `
  -Body $body
```

1. Откройте **http://localhost:3000**

3. Выберите **язык** текста

## Troubleshooting

### Ошибка: "API key is missing"

**Решение**: Проверьте, что ключ добавлен в `backend/.env` и backend перезапущен

```powershell
docker compose restart backend
```

### Ошибка: "Invalid API key" (Yandex)

**Причины**:

1. Неверный формат ключа
2. API Translate не активирован
3. Недостаточно прав у сервисного аккаунта

**Решение**: Проверьте роль `ai.translate.user` и активацию API

### Ошибка: "API key not valid" (Google)

**Причины**:

1. Cloud Translation API не включён
2. Ключ удалён или ограничен
3. Превышен лимит запросов

**Решение**:

1. Проверьте статус API в консоли
2. Проверьте ограничения ключа
3. Проверьте биллинг аккаунт

### Ошибка: "Authorization failure" (DeepL)

**Причины**:

1. Неверный формат ключа
2. Использован Pro endpoint для Free ключа (или наоборот)
3. Превышен лимит

**Решение**:

1. Проверьте, что ключ Free заканчивается на `:fx`
2. В коде Textropy автоматически определяется тип ключа
3. Проверьте использование в аккаунте DeepL
