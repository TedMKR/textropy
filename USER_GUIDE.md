# Руководство пользователя Textropy

## Быстрый старт

### Запуск приложения

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd textropy

# 2. Запустить Docker контейнеры
docker-compose up -d

# 3. Открыть в браузере
http://localhost
```

### Остановка

```bash
docker-compose down
```

## Основной интерфейс

### 1. Настройка перевода

**Исходный язык текста**

- Выберите язык вашего текста (по умолчанию: Русский)
- Доступные языки: русский, английский, немецкий, французский и др.

**Промежуточный язык перевода**

- Язык для двойного перевода (оригинал → промежуточный → оригинал)
- Рекомендуется выбирать языки с другой языковой семьей (например, суахили для русского текста)

### 2. Ввод текста

**Способ 1: Ручной ввод**

- Вставьте или введите текст в текстовое поле
- Минимум: ~50 слов для корректного анализа
- Оптимально: 100-500 слов

**Способ 2: Загрузка файла**

- Нажмите кнопку "Загрузить файл"
- Поддерживаемые форматы: `.txt`, `.doc`, `.docx`
- Максимальный размер: ~10000 символов

### 3. Запуск анализа

Нажмите кнопку **"Запустить Полный Цикл Перевода и Анализа"**

Процесс занимает 2-6 секунд:

1. ✓ Анализ оригинального текста
2. ✓ Перевод на промежуточный язык
3. ✓ Обратный перевод
4. ✓ Анализ результата
5. ✓ Сравнение метрик

## Результаты анализа

### Метрики потерь

**Потеря энтропии (ΔH)**

- Изменение информационной энтропии после двойного перевода
- Красный цвет: потеря информации
- Зеленый цвет: увеличение энтропии (редко)

**Δχ (Mean)**

- Изменение математического ожидания
- Показывает сдвиг распределения букв

**Δσ (StdDev)**

- Изменение стандартного отклонения
- Показывает изменение разброса частот

**Слов в анализе**

- Общее количество проанализированных слов

### График сравнения энтропий

Столбчатая диаграмма с тремя значениями:

- 🟢 **Оригинал** - энтропия исходного текста
- 🔵 **Перевод** - энтропия промежуточного перевода
- 🔴 **Обратно** - энтропия обратного перевода

### Топ-10 изменений букв

Таблица с буквами, частота которых изменилась больше всего:

- **Буква** - буква алфавита
- **Оригинал** - частота в исходном тексте (%)
- **После** - частота после двойного перевода (%)
- **Изменение** - разница частот

### Гистограммы распределения

#### Пара 1: По алфавиту

**Слева (зеленый):** Оригинал, сортировка по алфавиту (а, б, в...)
**Справа (красный):** Обратный перевод, сортировка по алфавиту

Показывает "нормальное" распределение букв в алфавитном порядке.

#### Пара 2: По частоте

**Слева (синий):** Оригинал, сортировка по возрастанию частоты
**Справа (красный):** Обратный перевод, сортировка по возрастанию

Показывает, как изменился порядок букв по популярности.

**Интерпретация:**

- Чем больше различий между левой и правой гистограммами, тем больше информационных потерь
- Одинаковые формы → хорошая сохранность информации
- Разные формы → значительные искажения

### Тексты для сравнения

Три панели с текстами:

1. **Оригинал** - исходный текст
2. **Перевод (XX)** - текст на промежуточном языке
3. **Обратный перевод** - текст после обратного перевода

Под каждым текстом указана энтропия (H).

## Интерпретация результатов

### Хорошее качество перевода

- Потеря энтропии: 0-5%
- Гистограммы визуально похожи
- Топ изменения букв: < 2%

### Среднее качество

- Потеря энтропии: 5-15%
- Заметные различия в гистограммах
- Топ изменения букв: 2-5%

### Плохое качество

- Потеря энтропии: > 15%
- Значительные различия в гистограммах
- Топ изменения букв: > 5%

## Рекомендации

### Выбор промежуточного языка

**Для максимальных потерь (тестирование устойчивости):**

- Суахили (sw) - для европейских языков
- Языки с иероглифами (китайский, японский)
- Языки с другой письменностью

**Для минимальных потерь:**

- Языки одной семьи (русский → украинский)
- Европейские языки между собой

### Качество текста

**Лучшие результаты:**

- Литературные тексты (стихи, проза)
- Тексты с разнообразной лексикой
- 100-500 слов

**Худшие результаты:**

- Тексты с повторяющимися словами
- Технические тексты с терминами
- Слишком короткие тексты (< 50 слов)

### Анализ изменений

1. Сначала смотрите на **потерю энтропии** - общий показатель
2. Изучите **график энтропий** - видна динамика изменений
3. Проверьте **топ-10 букв** - какие буквы изменились больше всего
4. Сравните **гистограммы** - визуальная оценка изменений
5. Прочитайте **обратный перевод** - качественная оценка

## Решение проблем

### Ошибка "Не удалось загрузить список языков"

- Проверьте, что backend запущен: `docker ps`
- Перезапустите контейнеры: `docker-compose restart`

### Ошибка при переводе

- Проверьте API ключи в `docker-compose.yml`
- Убедитесь в наличии интернет-соединения
- Проверьте лимиты Yandex Translate API

### Медленная работа

- Нормальное время: 2-6 секунд
- Если > 10 секунд: проблемы с API или интернетом
- Проверьте логи: `docker-compose logs backend`

### Пустые гистограммы

- Убедитесь, что текст содержит минимум 20-30 слов
- Проверьте, что выбран правильный исходный язык
- Попробуйте другой текст

## Технические детали

### Порты

- Frontend: `http://localhost` (80)
- Backend API: `http://localhost:8080`
- Swagger: `http://localhost:8080/swagger/index.html`

### API эндпоинты

```bash
# Health check
curl http://localhost:8080/health

# Список языков
curl http://localhost:8080/api/v1/languages

# Полный цикл перевода
curl -X POST http://localhost:8080/api/v1/translate-analyze \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Ваш текст здесь",
    "source_language": "ru",
    "target_language": "sw",
    "translator": "yandex"
  }'
```

### Логи

```bash
# Все контейнеры
docker-compose logs

# Только backend
docker-compose logs backend

# Только frontend
docker-compose logs frontend

# Последние 50 строк
docker-compose logs --tail=50
```

## Теоретическая справка

**Энтропия Шеннона (H)**

- Мера неопределенности/информативности текста
- Измеряется в битах
- Чем выше H, тем более равномерное распределение букв

**Математическое ожидание (χ)**

- Среднее значение "позиции" букв
- Показывает центр распределения

**Стандартное отклонение (σ)**

- Мера разброса распределения
- Высокое σ = большая вариативность частот

**Потеря информации**

- Естественное явление при переводе
- Зависит от языковой пары
- Больше при переводе через далекие языки
