## Анализ текста

### Алгоритм энтропийного анализа

Textropy использует **формулу Шеннона** для расчета информационной энтропии:

```
H = -Σ(Pᵢ × log₂(Pᵢ))
```

### Этапы анализа:

#### 1. Предобработка текста

- Извлечение слов из текста
- Нормализация (приведение к нижнему регистру)
- Удаление пунктуации и специальных символов
- Фильтрация пустых строк

#### 2. Подсчет частот

- Группировка слов по **начальной букве**
- Подсчет количества слов для каждой буквы
- Вычисление общего количества слов N

#### 3. Расчет вероятностей

Для каждой буквы i:

```
Pᵢ = nᵢ / N
```

Где:

- nᵢ - количество слов, начинающихся с буквы i
- N - общее количество слов

#### 4. Энтропия Шеннона

```
H = -Σ(Pᵢ × log₂(Pᵢ))
```

Чем выше H, тем более "равномерно" распределены буквы

#### 5. Статистические показатели

**Хи-квадрат (χ²)**:

```
χ² = Σ((nᵢ - E)² / E)
```

Где E = N / количество_букв

**Стандартное отклонение (σ)**:

```
σ = √(Σ((nᵢ - μ)² / N))
```

Где μ - среднее значение

### Результаты анализа

Система предоставляет:

- 📊 **Энтропия** - мера неопределенности
- 📈 **Частотное распределение** - для каждой буквы
- 📉 **Статистика** - χ², σ, средние значения
- 🎯 **Интерпретация** - оценка равномерности распределения

### Пример результата:

```json
{
  "entropy": 4.12,
  "word_count": 150,
  "unique_letters": 28,
  "chi_square": 31.25,
  "standard_deviation": 5.59,
  "letter_statistics": [
    {
      "letter": "п",
      "count": 25,
      "probability": 0.167,
      "entropy_contribution": 0.42
    }
  ]
}
```

## Переводчики

Textropy поддерживает интеграцию с тремя популярными сервисами перевода.

### 1. Yandex Translate

#### Особенности:

- ✅ Высокое качество для русского языка
- ✅ Быстрая скорость обработки
- ✅ API v2 с поддержкой batch перевода

#### Поддерживаемые языки:

- Русский (ru)
- Английский (en)
- Более 90 языков

#### API Endpoint:

```
https://translate.api.cloud.yandex.net/translate/v2/translate
```

#### Получение ключа:

1. Перейти на https://cloud.yandex.ru/
2. Создать сервисный аккаунт
3. Сгенерировать API ключ
4. Добавить в `.env`: `YANDEX_API_KEY=your_key`

### 2. Google Translate

#### Особенности:

- ✅ Самая большая база языков (100+)
- ✅ Отличное качество нейронного перевода
- ✅ Поддержка контекстного перевода

#### Поддерживаемые языки:

- Русский (ru)
- Английский (en)
- 100+ языков

#### API Endpoint:

```
https://translation.googleapis.com/language/translate/v2
```

#### Получение ключа:

1. Перейти на https://console.cloud.google.com/
2. Активировать Cloud Translation API
3. Создать API ключ
4. Добавить в `.env`: `GOOGLE_API_KEY=your_key`

### 3. DeepL

#### Особенности:

- ✅ Лучшее качество перевода (по мнению пользователей)
- ✅ Естественный стиль перевода
- ✅ Free и Pro планы

#### Поддерживаемые языки:

- Русский (RU)
- Английский (EN)
- 30+ языков

#### API Endpoint:

```
https://api-free.deepl.com/v2/translate  # Free
https://api.deepl.com/v2/translate       # Pro
```

#### Получение ключа:

1. Зарегистрироваться на https://www.deepl.com/pro-api
2. Выбрать Free или Pro план
3. Получить Authentication Key
4. Добавить в `.env`: `DEEPL_API_KEY=your_key`

## Темы оформления

### Тройной переключатель тем

Уникальная особенность Textropy - **3-way theme switch**:

```
[ Системная ] [ Светлая ] [ Темная ]
```

### 1. Светлая тема (Light Theme)

#### Цветовая палитра:

- **Фон**: #F5FFFA (Mint Cream) - освежающий мятный оттенок
- **Элементы**: #00A779 (Persian Green) - акцентный цвет
- **Текст**: #1F2937 (Gray 900) - темно-серый
- **Границы**: #E5E7EB (Gray 200) - светло-серый

#### Подходит для:

- ☀️ Дневной работы
- 🖥️ Ярко освещенных помещений
- 📝 Длительного чтения

### 2. Темная тема (Dark Theme)

#### Цветовая палитра:

- **Фон**: #0F172A (Slate 900) - глубокий темно-синий
- **Элементы**: #00A779 (Persian Green) - сохраняется акцент
- **Текст**: #F9FAFB (Gray 50) - почти белый
- **Границы**: #374151 (Gray 700) - темно-серый

#### Подходит для:

- 🌙 Ночной работы
- 💻 Слабо освещенных помещений
- 👀 Снижения нагрузки на глаза

### 3. Системная тема (System Theme)

- Автоматически следует настройкам операционной системы
- Переключается при изменении системной темы
- Использует `prefers-color-scheme` media query

#### Реализация:

```typescript
const systemTheme = window.matchMedia('(prefers-color-scheme: dark)').matches 
  ? 'dark' 
  : 'light';
```

### Переключение темы

#### UI компонент:

```tsx
<ThemeSwitch>
  <button active={theme === 'system'}>⚙️</button>
  <button active={theme === 'light'}>☀️</button>
  <button active={theme === 'dark'}>🌙</button>
</ThemeSwitch>
```

#### Сохранение выбора:

- В `localStorage` браузера
- Автоматическое применение при следующем визите
